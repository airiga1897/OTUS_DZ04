# Ресурсы учебного стенда

Ресурсы выбраны для выполнения задания на пяти ВМ с ограничением расходов.

| Назначение | Количество | vCPU / RAM на ВМ | Диски на ВМ |
| --- | ---: | --- | --- |
| Nginx | 2 | 1 / 1 ГБ | HDD 10 ГБ |
| Django/uWSGI и GFS2 | 2 | 1 / 2 ГБ | HDD 10 ГБ + 1 ГБ данных |
| PostgreSQL и qnetd | 1 | 1 / 1 ГБ | HDD 10 ГБ |

Итого: 5 vCPU, 7 ГБ RAM, 52 ГБ HDD.
Для фронтов и БД используется доля CPU 20%, для backend — стандартные vCPU.
Дополнительно создаются Octavia HA, три floating IP, роутер и приватная сеть.

Размеры подходят для учебной проверки архитектуры и отказов отдельных узлов.
Для промышленной нагрузки требуется отдельный подбор ресурсов.

После проверки стенд удаляется командой:

```powershell
.\scripts\selectel-cleanup.ps1
```

Остановка ВМ не удаляет диски, IP и балансировщик. Удаление ресурсов
выполняется отдельно от развёртывания и проверок.
